# 星愿 · Xingyuan

iOS 优先的个人目标、打卡和日记应用，使用 Flutter、Dart 与 SQLite。
个人记录可以离线使用，无需加入小组；私密陪伴、云端能力和 AI 为可选配置。

## 功能

- 每日习惯、指定星期和单次目标，打卡、撤销、历史与本人提醒。
- 私人随手记、每日一篇日记、照片与独立草稿。
- 自愿配对、选择性分享和私聊，不提供排行榜或替他人完成任务。
- 经同意且主动触发的文字润色、日记生成和规划建议。
- 规划 Agent 的工具协议、确认保存保护及离线合成评测。

Agent 与部分无障碍体验仍在开发验证中。自动测试通过不等于真实模型质量、
iOS 模拟器交互、VoiceOver 或手机验收完成。

## 本地运行

验证工具链为 Flutter 3.47.6 / Dart 3.13.5。iOS 开发需要 macOS 与 Xcode。

```sh
flutter pub get --enforce-lockfile
flutter run -d <your-ios-simulator-id>
```

不配置后端也可使用个人离线记录。仓库不提供可用的公共 AI 或陪伴服务。
`config/*.example.json` 中的地址与凭据均为示例，不能直接连到原项目服务。
真机签名时请设置自己的唯一 Bundle ID 和 Apple 开发团队；示例标识不要用于覆盖已有安装。

## 目录

| 目录 | 内容 |
| --- | --- |
| `lib/` | Flutter 客户端与本地数据层 |
| `packages/xingyuan_core/` | 共享协议、日历与校验规则 |
| `server/` | 设备鉴权、可选陪伴与 AI 后端 |
| `test/`、`integration_test/` | 合成组件测试与独立 iOS 验证入口 |
| `tool/assistant_eval/`、`tool/agent_eval/` | 默认离线的评测工具 |
| `drift_schemas/` | 数据库迁移快照 |
| `supabase/` | 可选云端能力的早期验证材料，不代表完整托管服务 |

开发与自托管说明见 [开发指南](docs/development.md)，隐私和报告要求见
[安全说明](SECURITY.md)。第三方代码与模板说明见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 隐私

目标和记录默认私密。分享需要主动选择，不因配对自动公开历史。
照片不用于 AI 请求；文本发送范围以授权界面和显式操作为准。
使用自己部署的后端前，应确认其鉴权、存储、日志和模型提供方的数据处理规则。
不要把 API 密钥、设备凭据、数据库、备份、真实日记或照片提交到 Git。
